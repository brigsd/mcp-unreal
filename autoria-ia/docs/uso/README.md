# AnimAI — uso

Entrada para a IA que trabalha em personagens e animações com o AnimAI,
sem desenvolver suas ferramentas. O conjunto ainda não foi implementado;
esta página organiza a trilha futura, não fornece comandos já disponíveis.

## O que esta trilha entregará

Começar por disponibilidade e preparação do personagem; escolher/importar uma
fonte; editar uma região e intervalo com preservações; comparar resultado e
evidências; fazer nova correção ou reverter; publicar em destino explícito.
Cada guia terá pré-requisitos, pedido completo, retorno esperado, limites,
falhas recuperáveis e próximo passo. Exemplos acompanharão as capacidades
realmente entregues, com versão testada e fixture reproduzível.

A skill prevista `animai-usar` encaminhará ao guia necessário. Não será preciso
ler planos, código, decisões históricas ou documentação de desenvolvimento
para operar capacidades disponíveis. Capacidade ausente deve ser declarada;
não inventar chamadas com base nesta proposta.

## Fronteira do papel

Corrigir uma animação não autoriza alterar o resolvedor, relaxar preservações
ou modificar rig/skin fora do pedido. Um defeito do conjunto gera diagnóstico
reproduzível para desenvolvimento, mantendo intacta a revisão aprovada.
O orçamento de iteração e o destino de publicação fazem parte do pedido.

Se a intenção for modificar o próprio conjunto, a entrada passa a ser
[desenvolvimento](../desenvolvimento/README.md). Para identificar o produto
ou trocar de papel, volte ao [índice AnimAI](../../README.md).
